## 현재 상태

Wails 3 기반 데스크톱 앱과 심플한 채팅 UI를 구성했습니다. OpenAI 호환 모델 조회, SSE 스트리밍 채팅, 오류 처리 및 생성 중단을 구현했으며 모의 HTTP 응답 기반 테스트와 macOS 앱 패키징을 통과했습니다. 실제 로컬 LLM 서버에서 모델 조회, 스트리밍 대화 및 긴 대화 스크롤이 정상 동작하는 것을 확인했습니다.

첫 번째 목표인 로컬 LLM 기본 채팅은 완료했습니다. 다음 구현 대상은 대화와 연결 프로필의 로컬 저장이며, 실제 서버에서 생성 중단 동작을 별도 검증 항목으로 남겨 둡니다.
