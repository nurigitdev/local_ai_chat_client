## 현재 상태

프로젝트 기반 문서를 구성하는 단계입니다. 아직 Wails 애플리케이션 소스는 생성하지 않았습니다.

현재 목표는 vLLM의 OpenAI 호환 API에 연결하여 모델을 선택하고, 스트리밍으로 대화하며, 실행 중인 생성을 취소할 수 있는 첫 번째 동작 버전을 만드는 것입니다.
