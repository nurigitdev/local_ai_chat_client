## 요청 구성

두 과제 모두 같은 20개 선택지와 서버 choice 응답을 사용한다. 내부 평가 유형은 단일 choice, 복합 ranking으로 구분한다. state.body에는 실제 요청만 전달하며 정답 목록·정답 개수·근거·문항 ID는 넣지 않는다. 간결형은 짧은 업무 정의, 상세형은 긴 경계 설명을 선택지에 제공한다. 서버 길이 제한은 별도로 적용된다. 모델별로 기준을 자동 축약하거나 답을 얻을 때까지 재시도하지 않는다.

## 복합 채점 기준

K는 사람이 지정한 정답 영역 수다. 모델에는 K를 알려주지 않는다. 모든 영역 확률을 내림차순 정렬한 상위 K개를 평가한다.

- 상위 목록 전체 일치율: 상위 K개가 정답 집합과 정확히 일치한 문항 비율. 주 지표다.
- 정답 영역 회수율: 상위 K개의 정답 영역 수 / K를 문항별로 계산해 평균한다. 부분 누락을 드러낸다.
- NDCG@K: 상위 K개의 정답 영역에 1/log2(순위+1)을 부여한 합을 정답 K개가 처음부터 나열된 이상적인 합으로 나눈다. 순위 품질 보조 지표다.
- 정답 영역 확률 합: 모든 정답 영역의 확률 합을 문항별로 계산해 평균한다. 한 영역에만 몰려도 높을 수 있으므로 단독 평가하지 않는다.
- 상위 K개와 다음 영역의 확률이 같으면 보기 순서로 채점하지 않는다. 해당 문항의 순위는 평가 불가로 남기고 확률 합은 계산한다.
- 확률이 누락되거나 범위·합 조건을 위반하면 복합 순위를 채점하지 않는다. 잘린 입력·오류·미실행은 품질 집계에서 제외한다.

상위 K 평가는 필요한 업무 개수 자체를 맞히는 평가가 아니다. 두 세트의 점수를 합쳐 단일 종합 순위를 만들지 않는다. 각 기본 문항의 정답은 사람 검토 후 확정해야 하며 점수가 오르게 정답을 변경하지 않는다.

## 기록과 호환성

세트 리비전·문항·정답·선택지·채점 규칙이 비교 지문에 포함된다. 이전 세트와 동일 조건 비교하지 않는다. 새 결과는 decision-benchmarks-v2에 저장하며 채점 버전은 business-domain-ranking-v2다. 이전 결과의 복원·통합·비교는 제공하지 않는다. 기본 설정 초안은 새 구성으로 갱신한다. 결과 화면과 독립 HTML 보고서에서 상위 목록 일치율, 순위 지표와 문항별 전체 확률을 확인한다.
